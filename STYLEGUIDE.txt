Pace style guide and code ownership

Keep the compact square design. Theme owns shared choices; views compose them;
controls own field geometry. Do not create a parallel theme.

Theme
  Palette: semantic colors, embedded original Pace Sans fonts, filled buttons.
  Warning is the sole attention role for expiry, limits, reconnect and errors;
  it shares the orange Above color. Do not add feature-specific warning colors.
  Palette owns enabled/disabled, selected, toggle, input, focus and button states.
  FilledButton paints filled text buttons, including disabled text and keyboard
  focus. IconButton keeps its intentionally distinct unfilled treatment.
  All action icons are drawn from the packaged Lucide SVGs at IconSize with
  UiMetrics.IconStroke, including settings.
  Returning to a reused window clears retained focus cues; subsequent deliberate
  keyboard navigation still shows its normal focus cue.
  Body 12px; account names SemiBold 14px; toolbar titles SemiBold 13.33px.
  All typography belongs here. Text uses Avalonia's normal layout and shaping
  (FormattedText, TextBlock); measure with Palette.TextWidth/TextHeight and
  ellipsize with Palette.Line. Do not substitute installed system fonts;
  self-tests verify the packaged families load without fallback.
  Tray hover uses AccountFont for names and BodyFont for numbers, as cards do.
  ThemedToolTip uses BodyFont and Palette colors for reset/error information.
  Avalonia owns tooltip placement; theme owns typography, painting and timing.
  UiMetrics: logical dimensions at 96 DPI, spacing, targets and tooltip timing.
  Shared border widths, focus insets, switch geometry, badge sizes and toolbar
  spacing belong here. Scale from BaseDpi, never a per-view DPI convention.
  Component-specific field coordinates remain local.
  Motion: steps on display frames; 200ms ease-out page handoff in which the
  window underneath stays opaque (Lead/Trail); 260ms popup ease-out;
  160ms reorder ease-out; 18px travel through Motion.SlideOffset. Respect the
  system animation preference.
  Fades animate WidgetWindow.FrameOpacity, never Window.Opacity. The window
  surface is transparent and the frame is composited once before opacity, so
  the whole window blends with the desktop. Back keeps the outgoing page in
  front until it finishes fading.

Presentation
  WidgetWindow: shared font, borderless transparent surface, frame border and
  FrameOpacity.
  PageDialog: separate native pages; shared placement, animation, dismissal,
  Escape and focus suppression. Never embed pages in UsagePanel.
  PageNavigation: simultaneous exit and entrance in both directions. Pages slide
  up on entry and down on Back; overview fades in place. Brief overlap is deliberate;
  only the destination remains afterward.
  UsagePanel owns the monitor for an open session. Refresh and navigation must
  not reanchor to the moving pointer.
  AccountsDialog: editor composition, debounced autosave and sign-in interactions.
  AccountDetailsDialog: identity, returned allowances and reset information.
  TrayHover: non-activating list; no separate hover font role.

Controls
  IconButton: unfilled Lucide button and keyboard focus cues. It intentionally
  differs from filled text buttons. Suppress outgoing outlines.
  AccountToggle: rectangular switch, BodyFont, Space support, keyboard-only focus.
  AccountRow and AccountEditorRow own layout and consume shared theme/domain rules.
  AccountRow and ResetBadge use ThemedToolTip only for the original information.
  Reset labels use local clock time, with a weekday on other calendar days.
  ResetBadge shares the reset-time line; Warning marks expiry within seven days. Missing
  dates remain unavailable; identical expiries combine with a trailing count.
  AnimatedAccountList owns reorder interpolation and saved row order.
  TrayDrawing uses native taskbar size and whole-pixel equal-width lines. Stronger
  blue is only for the tray; gray means unavailable/stale.

Logic and infrastructure
  Services names the Claude and Codex identifiers; UsageLimit names limit keys.
  PaceMath solely owns baseline, classification and labels. Inclusive tolerance:
  -4 through +2 percentage points. Palette maps classifications to colors.
  Each account uses its actual allowance period/reset. Ahead hours measure the
  current gap, rounded to approximate whole hours, not a forecast.
  BankedResets owns availability, expiry grouping and seven-day warnings.
  AccountRules owns the four-account limit.
  Settings owns names, visibility, order, removal and atomic persistence.
  Providers partial files separate discovery, parsing, limits, resets and fetching.
  SignIn owns invisible official CLI login and discards potentially sensitive output.
  NativeTrayIcon owns registration and suppresses native tooltip text.
  TrayApp coordinates refresh and views with one active-page reference.
  A refresh requested during a refresh runs once afterward instead of being lost.
  Preserve old readings on failed refreshes; fetch sequentially to avoid bursts.
  Credential discovery and reads run off the UI thread.
  Settings never overwrites a file it could not read; it keeps a copy first.
  ErrorLog records only exception type and stack for unexpected errors.
  AppTiming and TrayToggle own refresh cadence and tray click decisions.

Verification and repository contents
  Program selects modes only. Diagnostics separates typography, pace, provider,
  editing, layout, navigation, preview and live checks.
  Build and offline tests verify lifecycle refactors. Render visual changes.
  Do not call authenticated endpoints to verify a layout/theme cleanup.
  scripts/Verify-Repository.ps1 scans the index for local data, suspected secrets,
  oversized files and theme ownership violations.
  Commit source and required assets only. Exclude credentials, settings,
  environments, generated previews/reports and builds.
  Preserve asset licenses and reference SVGs. Follow .editorconfig.

Artwork and fonts
  Reuse the packaged service artwork and bundled font files. Never redraw the
  Lucide icons; IconArtwork strokes their SVG paths. The refresh icon turns
  slowly (Motion.SpinMilliseconds) while a refresh runs.
  Mouse focus is quiet. Selected filled buttons have no selection outline;
  keyboard focus alone displays Pace's outline. Icon buttons have no tooltips.
  App icon keeps its line pixels with transparent surrounding pixels.
  Layout derives from measured text and shared metrics, not fixed pixel targets.
